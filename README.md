# Кагэ — библиотека событий

Фронтенд для лабораторной работы №1 по NoSQL. Интерфейс работает с Spring Boot API из каталога `backend/nosql_lab1`: события и заявки хранятся в PostgreSQL, а настройки, временные заявки и счётчики просмотров — в Redis.

## Запуск

Из корня проекта выполните:

```bash
./start.sh
```

Скрипт создаст `backend/.env`, если его ещё нет, соберёт Spring Boot, поднимет PostgreSQL, Redis, Keycloak и backend через Docker Compose, установит зависимости frontend при необходимости и запустит Vite. После проверки готовности он напечатает адреса сервисов в консоль.

Frontend открывается по адресу `http://localhost:5173`.

Тестовые аккаунты Keycloak:

- менеджер: `manager` / `manager`;
- читатель: `reader` / `reader`.

Keycloak доступен по адресу `http://localhost:8181`, API — `http://localhost:8180`. Внешние порты сервисов перенесены в локальном `.env`, чтобы не конфликтовать с уже запущенными процессами на машине. Vite проксирует `/api` и `/auth` на бэкенд, поэтому отдельная CORS-конфигурация для локальной разработки не требуется.

Первый вход создаёт связанный профиль приложения. Его UUID сохраняется в `localStorage`, поскольку текущий API пока не умеет искать профиль по email или извлекать его из JWT.

## Возможности

- самостоятельная регистрация и OAuth2-вход через Keycloak с автоматическим созданием профиля;
- поиск и постраничная афиша событий;
- атомарный счётчик просмотров;
- временная заявка в Redis на 15 минут;
- создание, подтверждение и отмена заявок;
- настройки пользователя с cache-aside и TTL 30 минут;
- создание и редактирование событий для менеджера;
- адаптивный аниме-интерфейс с оригинальными иллюстрациями.
